# Design direction

Premium exploration, with historical character. Deep green-charcoal surfaces, warm white text, a sharp pale-lime accent, confident sans-serif headlines, and selective editorial serif typography. No horror, Halloween styling, decorative skulls, or sensationalism.

The initial homepage is intentionally typographic. Licensed historical photography can be added with verified attribution; never substitute fabricated portraits for real people. The primary future action is “Find the dead near me,” with “Explore the map” secondary. This foundation uses working in-page preview links until those flows exist.

Mobile-first stacked content, roomy tap targets, strong contrast, visible keyboard focus, skip link, semantic landmarks, and reduced-motion support. Avoid unverified counts or implied distances. Future bottom sheets need focus management, Escape/dismissal, and a non-map list alternative. Permission denial must offer manual location or the default region without implying it is the visitor's location.

Future person metadata uses server-generated titles, descriptions, canonical URLs, Open Graph and appropriate Person structured data. Cemetery pages use Place/Cemetery where supported. Preview is noindex; indexing is enabled only with reviewed substantive records. Do not include drafts, fixtures or empty profiles in sitemaps.
